# 🚀 XhuuLL Cyber-Neon Portfolio

![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-black?style=for-the-badge&logo=framer&logoColor=blue)

Portfolio personal bergaya **Cyber-Neon & Dark Developer Aesthetic**, dibangun menggunakan teknologi modern web dengan performa tinggi. Situs ini memuat interaksi animasi tingkat lanjut, *fluid WebGL background*, dan pemutar musik bawaan *(built-in)*.

## ✨ Fitur Utama

- 🌌 **Liquid Ether Background:** Latar belakang *fluid* dan imersif menggunakan Native WebGL (Terinspirasi oleh *React Bits*).
- 🧩 **Advanced UI Interactions:**
  - **Scrambled Text:** Efek dekripsi/hacker saat memuat halaman About.
  - **Scroll Stack Layout:** Tampilan project yang saling tertumpuk elegan seiring Anda melakukan *scroll*.
  - **Dock Navigation:** Navigasi bergaya macOS dock di bawah layar dengan *glassmorphism* dan animasi hover yang halus.
- 🎵 **Built-in Music Player (Fun Zone):** Pemutar musik canggih yang dibangun menggunakan `Howler.js` dan sinkronisasi status UI.
- 🎨 **Solid Dark Mode:** Desain konsisten pada kegelapan dengan aksen warna dominan *Neon Pink, Cyan, dan Purple*.
- 🔊 **Sound Effects:** Menambahkan umpan balik audio *(audio feedback)* ringan untuk setiap hover dan klik pada komponen utama.

## 🛠️ Teknologi yang Digunakan

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Audio Control:** [Howler.js](https://howlerjs.com/)
- **Icons:** [Lucide-React](https://lucide.dev/)

## 🚀 Cara Menjalankan Proyek secara Lokal

Ikuti langkah-langkah di bawah ini untuk menjalankan website portfolio ini di komputer Anda:

### 1. Prasyarat (Prerequisites)
Pastikan Anda sudah menginstal:
- [Node.js](https://nodejs.org/) (Versi 18 LTS ke atas direkomendasikan)
- [Git](https://git-scm.com/)

### 2. Kloning Repositori
Buka terminal Anda dan jalankan perintah berikut untuk mengkloning repositori:
```bash
git clone https://github.com/XhuuLL/Portfolio-Next.git
cd Portfolio-Next
```

### 3. Install Dependensi
Instal semua modul yang dibutuhkan. Anda bisa menggunakan `npm`, `yarn`, `pnpm`, atau `bun`. Di sini kita contohkan menggunakan `npm`:
```bash
npm install
```
*(Catatan: Jika terdapat conflict dependencies saat instalasi, Anda bisa menambahkan flag `--legacy-peer-deps`)*

### 4. Mulai Development Server
Setelah proses instalasi selesai, jalankan server pengembangan *(development server)*:
```bash
npm run dev
```

### 5. Buka di Browser
Website Anda sekarang telah berjalan! Buka peramban *(browser)* kesayangan Anda dan akses URL berikut:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 📦 Build untuk Produksi (Opsional)
Jika Anda ingin mengetes performa asli atau melakukan *deploy*, buat file siap-produksi dengan cara:
```bash
npm run build
npm run start
```
